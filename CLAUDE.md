# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

A fine-tuning pipeline that creates a D&D content generation model by fine-tuning TinyLlama-1.1B-Chat with QLoRA on synthetic data generated via the Claude API. The output is a GGUF-quantized model runnable with Ollama.

## Pipeline

Four numbered scripts run in sequence (`./run_all.sh` runs all):

| Step | Script | Input | Output | Time |
|------|--------|-------|--------|------|
| 1 | `01_generate_data.py` | Claude API | `data/dnd_training.jsonl` | ~10 min |
| 2 | `02_train.py` | training JSONL | `output/` (LoRA adapter) | ~15-30 min |
| 3 | `03_merge_and_export.py` | LoRA adapter + base model | `merged_model/` + `gguf/*.gguf` | ~5 min |
| 4 | `04_push_to_hub.py` | merged model + GGUF | HuggingFace Hub | ~2 min |

Run individual steps: `python3 01_generate_data.py` (activate `.venv` first).

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Requires `.env` with `ANTHROPIC_API_KEY` and `HF_TOKEN` (see `.env.example`).

Step 3 needs `cmake` and a C compiler (builds llama.cpp's quantize tool). Step 2 needs an NVIDIA GPU with 8GB+ VRAM.

## Architecture Notes

- **Data generation** uses weighted categories (npc, quest, dialog, location, encounter) with randomized prompt variations for diversity. Data format is chat-style JSONL with system/user/assistant messages.
- **Training** uses QLoRA (4-bit NF4 + LoRA r=64) via `SFTTrainer` from TRL. Chat template is applied via tokenizer. 95/5 train/eval split.
- **GGUF conversion** clones llama.cpp on first run, converts to F16 intermediate, then quantizes to Q4_K_M. F16 file is deleted after quantization.
- **HF upload** targets `JBHarris/dm-llm-tiny`. Pushes both the full merged model and the GGUF file.
- The `Modelfile` uses TinyLlama's chat template format (`<|system|>`, `<|user|>`, `<|assistant|>`) for Ollama.

## Key Constants

Tunable values are at the top of each script (e.g., `NUM_EXAMPLES`, `EPOCHS`, `LORA_R`, `BASE_MODEL`). Changing `BASE_MODEL` requires updating it in both `02_train.py` and `03_merge_and_export.py`.

## Generated Directories (gitignored)

`data/`, `output/`, `merged_model/`, `gguf/`, `llama.cpp/` — all generated by the pipeline and excluded from git.
